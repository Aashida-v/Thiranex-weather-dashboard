# Thiranex Weather Dashboard

A responsive Weather Dashboard built using HTML, CSS, and JavaScript. It fetches current weather information from public REST APIs based on the city entered by the user.

## Features

- Search weather by city name.
- Fetch weather data using the JavaScript Fetch API.
- Use async/await for asynchronous operations.
- Display temperature, humidity, and wind speed.
- Display feels-like temperature and weather conditions.
- Show weather icons.
- Handle invalid city names and API errors.
- Responsive design for mobile and desktop screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Open-Meteo Geocoding API
- Open-Meteo Weather API

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if needed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
6. Enter a city name and click Search.
